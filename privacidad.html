Política de privacidad

Última actualización: 27 de agosto de 2026

Mis Tickets es una aplicación web para organizar compras, fotografías o PDF de tickets, garantías y datos asociados. Esta política explica cómo trata la aplicación la información del usuario.

1. Datos guardados en el dispositivo

Las compras, tickets, tiendas, precios, fechas, números de serie y demás información introducida se guardan inicialmente en la base de datos privada del navegador del usuario. Mis Tickets no dispone de un servidor propio que reciba o centralice estos datos.

2. Acceso opcional a Google Drive

Solo cuando el usuario decide conectar su cuenta, Mis Tickets solicita el permiso limitado drive.file. Este permiso permite crear y gestionar únicamente los archivos y carpetas de Google Drive creados por la propia aplicación; no permite leer libremente el resto del contenido de Drive.

La aplicación utiliza este acceso exclusivamente para crear una carpeta denominada “Mis Tickets” y copiar en ella los justificantes y datos de las compras registrados por el usuario.

3. Uso y comunicación de los datos de Google

Los datos obtenidos mediante Google Drive no se venden, no se utilizan para publicidad y no se comparten ni transfieren a terceros. La aplicación no utiliza los datos de Google para entrenar modelos, elaborar perfiles ni realizar análisis comerciales.

4. Seguridad

La comunicación con Google se realiza mediante HTTPS y la autorización oficial OAuth 2.0 de Google. El token temporal de acceso se conserva únicamente durante la sesión activa del navegador y no se incluye en las copias ni en el código público de la aplicación.

5. Conservación y eliminación

  • Los datos locales se conservan hasta que el usuario los elimina desde la aplicación o borra los datos del sitio en su navegador.
  • Las copias creadas en Google Drive permanecen en la cuenta del usuario hasta que este las elimina desde su propio Drive.
  • Desconectar Drive revoca el acceso de la aplicación, pero no elimina automáticamente las copias que ya existen.
  • El usuario puede retirar el acceso desde la configuración de seguridad de su cuenta de Google.

6. Servicios utilizados

La aplicación se publica mediante GitHub Pages y utiliza Google Identity Services y Google Drive API cuando el usuario activa voluntariamente la copia en Drive. Estos servicios están sujetos a sus propias políticas.
