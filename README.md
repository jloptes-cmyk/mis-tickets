# Mis Tickets

Aplicación web instalable para organizar compras, tickets, números de serie y garantías.

## Funciones

- Inventario de objetos y tickets.
- Fotografía o PDF del justificante.
- Escáner EAN, UPC y QR cuando el navegador es compatible.
- Almacenamiento privado mediante IndexedDB.
- Exportación e importación de copias completas.
- Funcionamiento sin conexión después de la primera carga.
- Instalación desde el navegador como aplicación.

## Privacidad

Esta edición no contiene datos ni credenciales de su autor. Cada navegador crea su propia base de datos local. Borrar los datos del sitio también borra esa copia local, por lo que conviene descargar copias periódicas hasta que la integración opcional con Google Drive esté activa.

## Google Drive

La interfaz está preparada para que cada usuario conecte su propia cuenta. La autorización automática todavía requiere configurar un cliente de Google OAuth para el dominio definitivo de GitHub Pages.

## Publicación

El flujo de GitHub Actions incluido publica automáticamente la rama `main` en GitHub Pages.
